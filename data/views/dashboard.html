供 Agent 读取

看板是规范 JSON 的派生视图。Agent 应读取原始文件，而不是解析页面文字；页面里的每个数字和链接都来自 data/。档案格式以 compose-profile 为准，赛道归入以 map-sectors 为准。

数据入口

  • data/index.json223 个机构的机器索引，含 ID、类型、批次、路径
  • data/companies/<id>.json完整档案：身份、业务、渠道、人物、地区、来源与核查日期
  • data/schemas/company / investor / person / channel / targeting / index 契约
  • data/taxonomy.json既有 01–10 赛道定义、边界与参考框架
  • data/views/assets/logos/manifest.json创业公司 logo 的官方来源、抓取日期或跳过原因

内嵌数据

页面包含 <script type="application/json" id="cn-ai-opp-data">，可直接取用。

{
  "meta": { "default_class": "startups", "generated_from": [...] },
  "labels": {...},
  "classes": [{ "id": "startups", "count": 102 }, ...],
  "taxonomy": {...},
  "logos": { "unitree": "assets/logos/unitree.png" },
  "organizations": [
    { "class": "startups", "logo": "...", "index": {...}, "record": {...} }
  ]
}

每条记录的 index.json_path 指向原始 JSON；详情面板提供“复制 JSON”和“原始 JSON”链接。Logo 只是派生视图资产，缺失时使用文字占位。
